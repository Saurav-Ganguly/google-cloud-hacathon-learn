#### 🛠 Phase 1: Core Frameworks & Environment

The first step is choosing your build environment. Whether you want a managed platform or a local setup, start here.

- Managed Setup: [Gemini Enterprise Agent Platform API Setup](https://console.cloud.google.com/) – The essential mission control for all Google Cloud agent projects.
- The Low-Code Path: [Agent Builder Guide](https://cloud.google.com/products/agent-builder) – Best for rapid development using managed orchestration, grounding, and enterprise data stores.
- Developer SDK: [Gemini Enterprise Agent Platform SDK for Python](https://cloud.google.com/python/docs/reference/aiplatform/latest) – The client library required for writing custom agent logic and handling tool calls.
- [Agent Starter Pack](https://github.com/GoogleCloudPlatform/agent-starter-pack)
- You can get access to Google Cloud in two ways:
1. Sign up for a no-cost trial at [cloud.google.com/free](https://rapid-agent.devpost.com/cloud.google.com/free)
2. Use an existing Google Cloud account and request $100 in credits: [https://forms.gle/xfv9vQzfRfNCCVbG7](https://forms.gle/xfv9vQzfRfNCCVbG7) (approved within 1–5 business days)

#### 🔗 Phase 2: Action Mechanisms & Data Connectivity

Agents need to "do" things and "know" things. Use these resources to give your agent agency over data and tools.

Core Action Mechanisms (Tool Use)

- Agent Builder Extensions: [Building & Managing Extensions](https://cloud.google.com/vertex-ai/docs/generative-ai/extensions/overview) – Use pre-built Google extensions or connect your managed agent to any external API.

Knowledge & Grounding

- Agent Builder Data Stores: [Agent Search and Agent Conversation Overview](https://cloud.google.com/vertex-ai/docs/generative-ai/agent-builder/overview) – Use this unified platform to index your PDFs, websites, or BigQuery tables and give your managed agent a "source of truth."

#### 🧠 Phase 4: Reasoning, State, & Logic Hosting

Complex missions require memory and a place for your code to live.

- Managed Orchestration: [Agent Runtime](https://cloud.google.com/vertex-ai/docs/generative-ai/reasoning-engine/overview) – A runtime for deploying Python-based agents (LangChain/LlamaIndex) built with Agent Builder or the SDK.
- State & Secrets: [Secret Manager](https://cloud.google.com/secret-manager) – Securely store and retrieve API keys for your partner integrations.

#### 🚀 Phase 5: Deployment & Safety

- Agent Deployment: Agent Builder Deployment – Learn how to make your managed agent accessible via a web interface or API.
- Custom Backend Hosting: [Cloud Run Quickstart](https://cloud.google.com/run/docs/quickstarts) – The go-to for hosting your own agent backends or custom-built tool servers.
- Safety & Guardrails: [Gemini Enterprise Agent Platform Safety Settings](https://cloud.google.com/vertex-ai/docs/generative-ai/learn/responsible-ai) – Configure filters to ensure your agent remains helpful and follows your defined constraints.
