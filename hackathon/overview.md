# Google Cloud Rapid Agent Hackathon — Overview

> **Deadline**: Jun 11, 2026 @ 5:00 PM EDT | **Prize Pool**: $60,000 | **Participants**: 6,077+

**Source**: https://rapid-agent.devpost.com/

---

## What Is It?

Build an **AI agent** (not just a chatbot) that reasons, plans, and executes real-world tasks — powered by **Gemini** and **Google Cloud Agent Builder**, integrating a partner's **MCP server**.

---

## The Challenge

- Move beyond chat: agents must use tools to accomplish tasks
- Handle multi-step goals with planning
- Integrate at least one partner's MCP server meaningfully

**Stack Required**: Gemini + Google Cloud Agent Builder + Partner MCP server

## What to Submit

1. URL to the **hosted project**
2. URL to **public open-source repo** (must have OSS license in About section)
3. **~3 minute demo video** (YouTube or Vimeo, in English)
4. Track selection
5. Completed Devpost submission form

---

## Judging Criteria

| Criterion | Question |
|-----------|----------|
| Technological Implementation | Quality of Google Cloud + Partner integration? |
