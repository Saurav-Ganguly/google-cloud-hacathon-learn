## Phase 1: Core Frameworks & Environment

Choose your build environment first:

| Path | Link | Notes |
|------|------|-------|
| Mission Control | [Google Cloud Console](https://console.cloud.google.com/) | Required for all agent projects |
| Low-Code | [Agent Builder Guide](https://cloud.google.com/products/agent-builder) | Managed orchestration, rapid prototyping |
| Python SDK | [Gemini Enterprise Agent Platform SDK](https://cloud.google.com/python/docs/reference/aiplatform/latest) | Custom agent logic + tool calls |
| Starter Pack | [agent-starter-pack (GitHub)](https://github.com/GoogleCloudPlatform/agent-starter-pack) | Boilerplate to get started fast |
