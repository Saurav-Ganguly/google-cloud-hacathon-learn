### Started streaming quickstart — hit Live API `1008 policy violation`

Scaffolded `test/adk_streaming` (`adk create`, model
`gemini-live-2.5-flash-native-audio`) for the [streaming quickstart](https://adk.dev/get-started/streaming/quickstart-streaming/).
`adk web` voice connect failed with `received 1008 (policy violation)` on
`locations/global/.../gemini-live-2.5-flash-native-audio`. Root cause (proven by
the rejected path + Google docs): **Vertex Live API models are not supported in
the `global` location**. The `.env` had `GOOGLE_CLOUD_LOCATION=global` (copied
from the agent-team setup, where non-Live models tolerate `global`).

**Fix**: set `test/adk_streaming/.env` → `GOOGLE_CLOUD_LOCATION=us-central1`
(matches the tutorial's own Vertex `.env` block). Code/`agent.py` was fine.

**Resolved**: after the `us-central1` fix, `adk web` voice + Google Search
grounding worked end-to-end. Streaming quickstart COMPLETE.
`test/adk_streaming/agent.py` kept as the canonical minimal streaming-agent
reference (Agent + `google_search` + Live model + Vertex `us-central1` .env).
