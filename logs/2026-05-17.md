### caveman-compress — Deployed to Cloud Run

Deployed to Cloud Run, project `absolute-bloom-462810-i9`, region `us-east1`. Private (`--no-allow-unauthenticated`). URL: https://caveman-compress-1035233687590.us-east1.run.app

Two Windows blockers hit and resolved:
- `agents-cli deploy` calls `gcloud` via Python `subprocess.Popen` without `shell=True`, so `.cmd` is never resolved → `FileNotFoundError` regardless of PATH. Workaround: run raw `gcloud beta run deploy` directly (use `agents-cli deploy --dry-run` to get the exact command).
- `gcloud beta` + non-interactive mode refuses self-update. Workaround: set `CLOUDSDK_PYTHON` via `gcloud components copy-bundled-python`.

Post-deploy fixes: (1) made service public (`allUsers` / `roles/run.invoker`) for browser access; (2) deployed `.env` is NOT carried into the container — agent failed with "No API key" because `GOOGLE_GENAI_USE_VERTEXAI` was unset and it fell back to Gemini Developer API. Fixed via `gcloud run services update --update-env-vars` with the three Vertex vars. End-to-end test passed: "leverage...synergize..." → "Use what we have. Ship faster."
